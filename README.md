# tobdev-media

Medios públicos de [@tobdev.ia](https://instagram.com/tobdev.ia): plantilla y videos del reel diario de noticias de IA.

- `plantilla/make_reel2.py` — generador del reel v2: voz IA (Kokoro), subtítulos palabra por palabra y escenas animadas (HyperFrames + música procedural). El guion se escribe según `plantilla/ESCENAS.md`; hay un ejemplo en `plantilla/ejemplo-guion.json`.
- `plantilla/make_reel.py` — plantilla vieja de 19 s, solo de respaldo.
- `videos/` — MP4 servidos por GitHub Pages para que Metricool los publique. Se borran a los pocos días (Metricool guarda su copia).
- `historial.json` — lo ya publicado, para no repetir.
- `TAREA.md` — instrucciones del agente programado.

Solo contenido propio de tobdev. Nunca material de clientes: este repo es público.
